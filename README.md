# claude-scifi-theme

A sci-fi look for the Claude desktop and mobile apps: a deep-space navy palette with neon cyan accents, and an animated backdrop behind the conversation — a twinkling starfield, drifting nebulae, a neon perspective grid running to a glowing horizon, and slowly turning HUD rings. Dark mode only; animation stops when the system asks for reduced motion. Terminal and editor sessions draw no theme.

## Install

At the prompt of a terminal session:

```
/plugin install scifi-look --marketplace nbhieu89-observer/claude-scifi-theme
```

Answer `y` to add the marketplace, then pick a scope (user scope applies it to every new session).

From a shell:

```bash
claude plugin install scifi-look --marketplace nbhieu89-observer/claude-scifi-theme
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins, Add marketplace with `nbhieu89-observer/claude-scifi-theme`, then Add plugin.

This repository is private: installing needs read access on GitHub and a git credential for github.com on the machine (an SSH key, or `gh auth login` then `gh auth setup-git`).
